Frequently Asked Questions about DOM Manipulation

What are the different ways to select an element in the DOM?

There are several methods to select DOM elements in JavaScript:

  • getElementById(): Selects a single element by its unique ID
  • getElementsByClassName(): Returns a collection of elements with a specific class name
  • getElementsByTagName(): Returns a collection of elements with a specific tag name
  • querySelector(): Returns the first element that matches a CSS selector
  • querySelectorAll(): Returns all elements that match a CSS selector
What is the difference between innerHTML, innerText and textContent?

textContent: Returns all text contained by an element and all its children, including text that is hidden by CSS. It preserves formatting and spacing.

innerText: Returns only the visible text contained by an element and its children, respecting CSS styling that hides elements.

innerHTML: Returns all text including HTML tags and markup contained within the element. It can be used to insert HTML content.

What is Event Delegation in DOM?

Event delegation is a powerful JavaScript pattern that efficiently handles events by leveraging event bubbling. Instead of adding event listeners to multiple child elements, you add a single event listener to a parent element.

Benefits:

  • Reduces memory usage
  • Works for dynamically added elements
  • Simplifies code maintenance
  • Improves performance for large lists
What is Event Bubbling in DOM?

Event bubbling is the process where an event propagates from the target element (where the event occurred) up through its parent elements in the DOM hierarchy, all the way to the document root.

Example: When you click a button inside a div, the click event first fires on the button, then bubbles up to the div, then to the body, and finally to the document. This behavior enables event delegation patterns.

How do you create, add, and remove elements using JavaScript?

Creating Elements:

const element = document.createElement('div');

Adding Elements:

  • appendChild(element): Adds a single element as the last child
  • append(element1, element2, ...): Adds one or multiple elements/text nodes
  • prepend(): Adds element as the first child
  • insertBefore(): Inserts element before a reference node

Removing Elements:

  • remove(): Removes the element from the DOM
  • removeChild(element): Removes a specific child element

Key Difference: appendChild() accepts only one element, while append() can accept multiple elements and text strings.
